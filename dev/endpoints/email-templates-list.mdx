Returns the email templates your team designed in the portal. Pass a template's `id` as `template_id` in [`POST /v1/email/send`](/dev/endpoints/email-send) to send it instead of a plain subject and body.

These are email templates, not WhatsApp templates. The WhatsApp catalog is [`GET /v1/templates`](/dev/endpoints/templates-list).

## Endpoint

```
GET https://api.keebai.com/v1/email/templates
```

## Required scope

`templates:read`

## Headers

| Header | Required | Value |
|---|---|---|
| `Authorization` | Yes | `Bearer kbai_pk_<token>` |

## Query parameters

| Field | Type | Required | Description |
|---|---|---|---|
| `search` | `string` | No | Filter by name. |

## Example request

<CodeGroup>

```bash curl
curl -G https://api.keebai.com/v1/email/templates \
  -H "Authorization: Bearer kbai_pk_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx" \
  --data-urlencode "search=bienvenida"
```

```js JavaScript
const params = new URLSearchParams({ search: "bienvenida" });

const response = await fetch(
  `https://api.keebai.com/v1/email/templates?${params}`,
  { headers: { Authorization: `Bearer ${process.env.KEEBAI_API_TOKEN}` } },
);
const { templates } = await response.json();
```

```python Python
import os, requests

resp = requests.get(
    "https://api.keebai.com/v1/email/templates",
    headers={"Authorization": f"Bearer {os.environ['KEEBAI_API_TOKEN']}"},
    params={"search": "bienvenida"},
    timeout=10,
)
resp.raise_for_status()
templates = resp.json()["templates"]
```

</CodeGroup>

## Response

### 200 OK

```json
{
  "templates": [
    {
      "id": "6651c2d3e4f5a6b7c8d9e0f1",
      "name": "Bienvenida",
      "subject": "Bienvenido a {{empresa}}",
      "category": "marketing",
      "variables": ["nombre", "empresa"],
      "updated_at": "2026-10-09T15:12:40.511Z"
    }
  ]
}
```

| Field | Type | Description |
|---|---|---|
| `id` | `string` | Template id. Pass it as `template_id` when sending. |
| `name` | `string` | Name shown in the portal. |
| `subject` | `string` | Subject line of the template. |
| `category` | `string` | Category set in the portal. |
| `variables` | `string[]` | Variables the template uses. Fill them per recipient with `recipients[].variables`. |
| `updated_at` | `string` | ISO 8601 timestamp of the last edit. |

### 401 Unauthorized

Missing, invalid, revoked, or expired token.

### 403 Forbidden

The token does not have the `templates:read` scope.

### 502 Bad Gateway

The messaging service could not answer.

## Operational notes

- **Only active templates are listed.** Templates are designed and edited in the portal; this API does not create or change them.
- **`variables` is always an array.** A template without variables returns `[]`, never `null`.
