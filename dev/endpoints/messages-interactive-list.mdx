Sends a message with a button that opens a scrollable menu. Use it when you have more options than the three [buttons](/dev/endpoints/messages-interactive-buttons) allow — a service catalogue, a list of branches, available time slots.

Only works inside the **24-hour window** since the recipient's last inbound message.

## Endpoint

```
POST https://api.keebai.com/v1/messages/interactive/list
```

## Required scope

`messages:send`

## Headers

| Header | Required | Value |
|---|---|---|
| `Authorization` | Yes | `Bearer kbai_pk_<token>` |
| `Content-Type` | Yes | `application/json` |

## Body

| Field | Type | Required | Description |
|---|---|---|---|
| `to` | `string` | Yes | Recipient phone number in E.164 format. |
| `phone_number_id` | `string` | Yes | WhatsApp Business `phone_number_id` of the sending number. |
| `body_text` | `string` | Yes | Message body. Up to 1024 characters. |
| `button_text` | `string` | Yes | Label of the button that opens the menu. Up to 20 characters. |
| `sections` | `array` | Yes | 1 to 10 sections. |
| `header` | `object` | No | `{ "type": "text", "text": "..." }`. |
| `footer_text` | `string` | No | Up to 60 characters. |
| `meta_data` | `object` | No | Free-form metadata persisted with the message. |

Each section:

| Field | Type | Required | Description |
|---|---|---|---|
| `title` | `string` | No | Section heading. Up to 24 characters. |
| `rows` | `array` | Yes | 1 to 10 rows: `{ "id": "...", "title": "...", "description": "..." }`. `title` up to 24 characters, `description` up to 72. |

## Response

### 202 Accepted

```json
{
  "message_id": "wamid.HBgLNTQ5MTE1NTU1NTU1FQIAERgSN0EyRjc4...",
  "status": "sent",
  "sent_at": "2026-05-02T14:31:07.221Z"
}
```

### 400 Bad Request

More than 10 sections, more than 10 rows in a section, a row `title` over 24 characters, a `description` over 72, or an unknown property.

### 401 Unauthorized

Missing, invalid, revoked, or expired token.

### 403 Forbidden

The token does not have the `messages:send` scope.

## Operational notes

- **10 sections × 10 rows is the API's shape, but Meta caps the total at 100 rows** across all sections. Keebai validates the per-section limits; the global cap is enforced upstream.
- **Row `id`s must be unique across the whole message**, not just within a section. Duplicates make the reply ambiguous.
- **24 characters for a row title is tight.** Put the detail in `description`, which gives you 72 more.
- **Sections with no `title` render as an unlabelled group.** With a single section, dropping the title usually looks cleaner.
