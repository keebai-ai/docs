Creates a tag category. Assign tags to it with `category_id` when you [create](/dev/endpoints/crm-tag-create) or [update](/dev/endpoints/crm-tag-update) them; a tag and its category must share the same scope.

The `company` and `project` are taken from your token and must **not** appear in the body. Sending them returns `400`.

## Endpoint

```
POST https://api.keebai.com/v1/crm/tag-categories
```

## Required scope

`crm:tags:write`

## Headers

| Header | Required | Value |
|---|---|---|
| `Authorization` | Yes | `Bearer kbai_pk_<token>` |
| `Content-Type` | Yes | `application/json` |

## Body

| Field | Type | Required | Description |
|---|---|---|---|
| `name` | `string` | Yes | Category name. Up to 100 characters. Unique per scope within the company. |
| `scope` | `string` | Yes | `ticket` or `client`. |
| `exclusive` | `boolean` | No | When `true`, a record carries at most one tag of this category. Defaults to `false`. |
| `order` | `integer` | No | Position in lists, `0` or more. Defaults to `0`. |

## Example request

<CodeGroup>

```bash curl
curl -X POST https://api.keebai.com/v1/crm/tag-categories \
  -H "Authorization: Bearer kbai_pk_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{ "name": "Segmento", "scope": "ticket", "exclusive": true }'
```

```js JavaScript
const response = await fetch("https://api.keebai.com/v1/crm/tag-categories", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.KEEBAI_API_TOKEN}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({ name: "Segmento", scope: "ticket", exclusive: true }),
});
const { category } = await response.json();
```

```python Python
import os, requests

resp = requests.post(
    "https://api.keebai.com/v1/crm/tag-categories",
    headers={"Authorization": f"Bearer {os.environ['KEEBAI_API_TOKEN']}"},
    json={"name": "Segmento", "scope": "ticket", "exclusive": True},
    timeout=10,
)
resp.raise_for_status()
category = resp.json()["category"]
```

## Response

### 201 Created

```json
{
  "category": {
    "_id": "6720a0f1e2d3c4b5a6978877",
    "name": "Segmento",
    "scope": "ticket",
    "exclusive": true,
    "order": 0,
    "created_at": "2026-10-02T12:58:03.114Z",
    "updated_at": "2026-10-02T12:58:03.114Z"
  }
}
```

### 400 Bad Request

- A category with the same `name` already exists in that scope (`Tag category name already exists for this scope`).
- Missing `name` or `scope`, a `scope` outside the allowed set, a negative `order`, or a property the endpoint does not accept — including `company` and `project`.

### 401 Unauthorized

Missing, invalid, revoked, or expired token.

### 403 Forbidden

The token does not have the `crm:tags:write` scope.
