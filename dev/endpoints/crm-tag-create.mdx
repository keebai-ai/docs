Creates a tag. The `scope` decides what it labels: `ticket` for pipeline tickets, `client` for customers and contacts. It cannot change later.

The `company` and `project` are taken from your token and must **not** appear in the body. Sending them returns `400`.

<Tip>
  A tag name is unique per scope. Before creating, [list the tags](/dev/endpoints/crm-tags-list) with `search` and reuse the one that already exists — that keeps reports grouped under a single tag.
</Tip>

## Endpoint

```
POST https://api.keebai.com/v1/crm/tags
```

## Required scope

`crm:tags:write`

## Headers

| Header | Required | Value |
|---|---|---|
| `Authorization` | Yes | `Bearer kbai_pk_<token>` |
| `Content-Type` | Yes | `application/json` |

## Body

| Field | Type | Required | Description |
|---|---|---|---|
| `name` | `string` | Yes | Tag name. Up to 100 characters. Unique per scope within the company. |
| `scope` | `string` | Yes | `ticket` or `client`. |
| `color` | `string` | No | Hex color shown in the portal. Defaults to `#1890ff`. |
| `category_id` | `string` | No | `ObjectId` of a [tag category](/dev/endpoints/crm-tag-categories-list) of the same scope. |

## Example request

<CodeGroup>

```bash curl
curl -X POST https://api.keebai.com/v1/crm/tags \
  -H "Authorization: Bearer kbai_pk_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Cliente VIP",
    "scope": "ticket",
    "color": "#f5a623",
    "category_id": "6720a0f1e2d3c4b5a6978877"
  }'
```

```js JavaScript
const response = await fetch("https://api.keebai.com/v1/crm/tags", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.KEEBAI_API_TOKEN}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({ name: "Cliente VIP", scope: "ticket", color: "#f5a623" }),
});
const { tag } = await response.json();
```

```python Python
import os, requests

resp = requests.post(
    "https://api.keebai.com/v1/crm/tags",
    headers={"Authorization": f"Bearer {os.environ['KEEBAI_API_TOKEN']}"},
    json={"name": "Cliente VIP", "scope": "ticket", "color": "#f5a623"},
    timeout=10,
)
resp.raise_for_status()
tag = resp.json()["tag"]
```

</CodeGroup>

## Response

### 201 Created

```json
{
  "tag": {
    "_id": "6720a1b2c3d4e5f6a7b8c9d0",
    "name": "Cliente VIP",
    "color": "#f5a623",
    "scope": "ticket",
    "category_id": "6720a0f1e2d3c4b5a6978877",
    "created_at": "2026-10-02T13:04:11.512Z",
    "updated_at": "2026-10-02T13:04:11.512Z"
  }
}
```

### 400 Bad Request

- A tag with the same `name` already exists in that scope (`Tag name already exists for this scope`).
- The category belongs to the other scope (`Tag scope must match its category scope`).
- Missing `name` or `scope`, a `scope` outside the allowed set, a malformed `category_id`, or a property the endpoint does not accept — including `company` and `project`, which are derived from the token.

### 401 Unauthorized

Missing, invalid, revoked, or expired token.

### 403 Forbidden

The token does not have the `crm:tags:write` scope.

### 404 Not Found

`category_id` does not match a category of your company (`Tag category not found`).

## Operational notes

- **Name uniqueness is an exact match.** `VIP` and `vip` are different names to this endpoint. Normalize names on your side before creating if your source system is loose about casing.
