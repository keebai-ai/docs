Queues delivery of a **Meta-approved template** to a single recipient. Useful for transactional notifications, reminders, and 1-to-1 messages triggered from your backend.

Under the hood, Keebai creates a broadcast with a single recipient, which lets you check its status later with [`GET /v1/messages/bulk/:broadcastId`](/dev/endpoints/messages-bulk-status).

## Endpoint

```
POST https://api.keebai.com/v1/messages/template
```

## Required scope

`messages:send`

## Headers

| Header | Required | Value |
|---|---|---|
| `Authorization` | Yes | `Bearer kbai_pk_<token>` |
| `Content-Type` | Yes | `application/json` |

## Body

| Field | Type | Required | Description |
|---|---|---|---|
| `to` | `string` | Yes | Recipient phone number in E.164 format (e.g. `+5491155555555`). |
| `phone_number_id` | `string` | Yes | WhatsApp Business `phone_number_id` of the sending number — the numeric id Meta issues, not a Keebai `ObjectId`. List yours with [`GET /v1/whatsapp/numbers`](/dev/endpoints/whatsapp-numbers). |
| `template_name` | `string` | Yes | Template name exactly as approved in Meta. |
| `language` | `string` | Yes | Template language code (`es`, `en`, `pt_BR`, etc.). |
| `variables` | `object<string, string>` | No | Map of named variables the template expects. Keys must match the template's `{{name}}` placeholders. The expected list is available via [`GET /v1/templates`](/dev/endpoints/templates-list). |
| `meta_data` | `object` | No | Free-form metadata persisted with the message. Useful to correlate with your system. |

## Example request

<CodeGroup>

```bash curl
curl -X POST https://api.keebai.com/v1/messages/template \
  -H "Authorization: Bearer kbai_pk_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "to": "+5491155555555",
    "phone_number_id": "109876543210987",
    "template_name": "welcome_v2",
    "language": "es",
    "variables": {
      "nombre": "Juan",
      "monto": "1500"
    },
    "meta_data": {
      "order_id": "ORD-2026-0042"
    }
  }'
```

```js JavaScript
const response = await fetch("https://api.keebai.com/v1/messages/template", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.KEEBAI_API_TOKEN}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    to: "+5491155555555",

    template_name: "welcome_v2",
    language: "es",
    variables: { nombre: "Juan", monto: "1500" },
  }),

```

```python Python
import os, requests

resp = requests.post(
    "https://api.keebai.com/v1/messages/template",
    headers={"Authorization": f"Bearer {os.environ['KEEBAI_API_TOKEN']}"},
    json={
        "to": "+5491155555555",
        "phone_number_id": "109876543210987",
        "template_name": "welcome_v2",
        "language": "es",
        "variables": {"nombre": "Juan", "monto": "1500"},
    },
    timeout=10,
)
resp.raise_for_status()
print(resp.json())
```

## Response

### 202 Accepted

The message was handed to WhatsApp. Delivery to the recipient's device happens asynchronously and is reported through [webhooks](/dev/webhooks/events).

```json
{
  "message_id": "wamid.HBgLNTQ5MTE1NTU1NTU1FQIAERgSN0EyRjc4...",
  "status": "sent",
  "sent_at": "2026-05-02T14:31:07.221Z"
}
```

| Field | Type | Description |
|---|---|---|
| `message_id` | `string` | Meta `message_id` (`wamid.*`). Correlate delivery and read webhooks with it. |
| `status` | `string` | `sent` when Meta accepted the message. |
| `sent_at` | `string` | ISO 8601 timestamp of the dispatch. |

<Note>
  Single sends return a `message_id`, not a `broadcast_id`. Only [`POST /v1/messages/bulk`](/dev/endpoints/messages-bulk) creates a broadcast you can poll.
</Note>

### 400 Bad Request

Invalid body (incorrect phone format, malformed `phone_number_id`, missing fields).

### 401 Unauthorized

Missing, invalid, revoked, or expired token.

### 403 Forbidden

The token does not have the `messages:send` scope.

```json
{
  "error": {
    "code": "INSUFFICIENT_SCOPE",
    "message": "Forbidden",
    "details": {
      "required": ["messages:send"],
      "missing": ["messages:send"]
    }
  }
}
```

### 502 Bad Gateway

Error contacting the upstream delivery service. Retry with backoff.

## Common patterns

### Transactional notification with correlation

```python
import os, requests

def notify_order(order_id: str, customer_phone: str, customer_name: str, amount: float):
    resp = requests.post(
        "https://api.keebai.com/v1/messages/template",
        headers={"Authorization": f"Bearer {os.environ['KEEBAI_API_TOKEN']}"},
        json={
            "to": customer_phone,
            "phone_number_id": os.environ["KEEBAI_PHONE_NUMBER_ID"],
            "template_name": "order_confirmation",
            "language": "es",
            "variables": {
                "nombre": customer_name,
                "monto": f"{amount:.2f}",
            },
            "meta_data": {"order_id": order_id},
        },
        timeout=10,
    )
    resp.raise_for_status()
    return resp.json()["broadcast_id"]
```
