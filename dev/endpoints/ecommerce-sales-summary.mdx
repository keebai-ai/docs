Returns the same report as **Ventas › Summary** in the portal, for one period. It is built for analysis: one call answers what was sold, when, and how it was paid.

Every amount is the **net sale** — the total charged minus the tip — of completed sales. A sale's net is spread over its lines by subtotal, so sale-level discounts land on the lines they cover and the three kinds add up exactly to the period's net sales.

## Endpoint

```
GET https://api.keebai.com/v1/ecommerce/sales/summary
```

## Required scope

`ecommerce:sales:read`

## Headers

| Header | Required | Value |
|---|---|---|
| `Authorization` | Yes | `Bearer kbai_pk_<token>` |

## Query parameters

| Field | Type | Required | Description |
|---|---|---|---|
| `from` | `string` | Yes | First day of the period, `YYYY-MM-DD`. |
| `to` | `string` | Yes | Last day of the period, inclusive, `YYYY-MM-DD`. |
| `branch_id` | `string` | No | One branch `ObjectId`, or several separated by commas. Without it, every branch and online store. |
| `timezone` | `string` | No | IANA time zone the days are cut in, e.g. `America/Santiago`. |

## Example request

<CodeGroup>

```bash curl
curl -G https://api.keebai.com/v1/ecommerce/sales/summary \
  -H "Authorization: Bearer kbai_pk_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx" \
  --data-urlencode "from=2026-11-01" \
  --data-urlencode "to=2026-11-30" \
  --data-urlencode "timezone=America/Santiago"
```

```js JavaScript
const params = new URLSearchParams({
  from: "2026-11-01",
  to: "2026-11-30",
  timezone: "America/Santiago",
});

const response = await fetch(
  `https://api.keebai.com/v1/ecommerce/sales/summary?${params}`,
  { headers: { Authorization: `Bearer ${process.env.KEEBAI_API_TOKEN}` } },
);
const summary = await response.json();
```

```python Python
import os, requests

resp = requests.get(
    "https://api.keebai.com/v1/ecommerce/sales/summary",
    headers={"Authorization": f"Bearer {os.environ['KEEBAI_API_TOKEN']}"},
    params={"from": "2026-11-01", "to": "2026-11-30", "timezone": "America/Santiago"},
    timeout=10,
)
resp.raise_for_status()
summary = resp.json()
```

```json
  "channels": { "branch": 7660000, "store": 757000 }

```

| Field | Description |
|---|---|
| `previous` | The period `kinds[].previous_amount` compares with: the same days of the previous month when `from` is the 1st, otherwise the window of the same length right before. |
| `kinds` | One row per kind of line: `service`, `product`, and `custom` (charges outside the catalog). `sales` counts the sales that include that kind. |
| `daily` | Every day of the period, by kind, including days with no sales. |
| `top` | The five best sellers of each kind by amount, grouped by product or catalog item; `rest` sums the others. |
| `weeks` | The last eight weeks, Monday to Sunday, ending with the week of `to` (cut at `to`). |
| `weekdays` | Average net sale per weekday (`0` = Sunday) over the days of the period already lived; `days` is how many there were. |
| `payments` | What was charged per payment method code, tips included. |
| `channels` | Net sales at a branch (`branch`) and in online stores (`store`). |

### 400 Bad Request

A missing or malformed `from` / `to`, `from` after `to`, a malformed `branch_id`, or an unknown time zone.

### 401 Unauthorized

Missing, invalid, revoked, or expired token.

### 403 Forbidden

The token does not have the `ecommerce:sales:read` scope.

### 502 Bad Gateway

`ECOMMERCE_UPSTREAM_ERROR` — the ecommerce service could not answer.

## Operational notes

- **Amounts are integers in the currency's minor unit.** Kinds are rounded one by one, so their sum can differ from the net sales by a unit.
- **Cancelled, internal and report-excluded sales are left out**, the same rule as the portal's sales reports.
- **Payment methods are codes** (`cash`, `debit`, a tenant's own method code…). They include the tip, so they add up to the total charged, not to the net.
- **For the list of the sales behind these figures** use [`GET /v1/ecommerce/sales`](/dev/endpoints/ecommerce-sales-list) with the same dates.
