Returns where a product's stock is. Each variant carries its master total, how much of it is allocated to branches, and how much is still in the warehouse.

## Endpoint

```
GET https://api.keebai.com/v1/ecommerce/products/{id}/stock
```

## Required scope

`ecommerce:stock:read`

## Headers

| Header | Required | Value |
|---|---|---|
| `Authorization` | Yes | `Bearer kbai_pk_<token>` |

## Path parameters

| Field | Type | Required | Description |
|---|---|---|---|
| `id` | `string` | Yes | `ObjectId` of the product. |

## Example request

<CodeGroup>

```bash curl
curl https://api.keebai.com/v1/ecommerce/products/65d3e4f5a6b7c8d9e0f1a2b3/stock \
  -H "Authorization: Bearer kbai_pk_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
```

```js JavaScript
const response = await fetch(
  `https://api.keebai.com/v1/ecommerce/products/${productId}/stock`,
  { headers: { Authorization: `Bearer ${process.env.KEEBAI_API_TOKEN}` } },
);
const { variants } = await response.json();
```

```python Python
import os, requests

resp = requests.get(
    f"https://api.keebai.com/v1/ecommerce/products/{product_id}/stock",
    headers={"Authorization": f"Bearer {os.environ['KEEBAI_API_TOKEN']}"},
    timeout=10,
)
resp.raise_for_status()
variants = resp.json()["variants"]
```

</CodeGroup>

## Response

### 200 OK

```json
{
  "product_id": "65d3e4f5a6b7c8d9e0f1a2b3",
  "variants": [
    {
      "variant_id": "65d3e4f5a6b7c8d9e0f1a2c1",
      "name": "42 / Negro",
      "total": 12,
      "allocated": 8,
      "warehouse_available": 4,
      "branches": [
        { "branch_id": "br_01", "quantity": 5 },
        { "branch_id": "br_02", "quantity": 3 }
      ]
    }
  ]
}
```

| Field | Type | Description |
|---|---|---|
| `product_id` | `string` | Same id you requested. |
| `variants[].variant_id` | `string` | `ObjectId` of the variant. |
| `variants[].name` | `string` | Variant name. |
| `variants[].total` | `number` | Master stock of the variant. |
| `variants[].allocated` | `number` | Part of the total assigned to branches. |
| `variants[].warehouse_available` | `number` | Part of the total still in the warehouse. |
| `variants[].branches` | `object[]` | Stock per branch: `branch_id` and `quantity`. |

### 401 Unauthorized

Missing, invalid, revoked, or expired token.

### 403 Forbidden

The token does not have the `ecommerce:stock:read` scope.

### 404 Not Found

No product with that id, or it belongs to a different company.

### 502 Bad Gateway

`ECOMMERCE_UPSTREAM_ERROR` — the ecommerce service could not answer.

## Operational notes

- **`total` is the master stock.** Branch quantities are a split of it, not an addition: `allocated` is what sits in branches and `warehouse_available` is what is left.
- **The same shape comes back from writes.** [Adjusting](/dev/endpoints/ecommerce-stock-adjust) or [transferring](/dev/endpoints/ecommerce-stock-transfer) stock responds with this body, so you do not need a follow-up read.
