Sends a free-form text message to a recipient. WhatsApp only allows free-form text inside the **24-hour window** since the user's last inbound message; if the window is closed, Meta will reject the message and the broadcast ends in `FAILED`. For sends outside the window, use [`POST /v1/messages/template`](/dev/endpoints/messages-template).

## Endpoint

```
POST https://api.keebai.com/v1/messages/text
```

## Required scope

`messages:send`

## Headers

| Header | Required | Value |
|---|---|---|
| `Authorization` | Yes | `Bearer kbai_pk_<token>` |
| `Content-Type` | Yes | `application/json` |

## Body

| Field | Type | Required | Description |
|---|---|---|---|
| `to` | `string` | Yes | Recipient phone number in E.164 format. |
| `phone_number_id` | `string` | Yes | WhatsApp Business `phone_number_id` of the sending number — the numeric id Meta issues, not a Keebai `ObjectId`. List yours with [`GET /v1/whatsapp/numbers`](/dev/endpoints/whatsapp-numbers). |
| `text` | `string` | Yes | Message body. Up to 4096 characters. |
| `preview_url` | `boolean` | No | Render link previews for URLs in the body. |
| `meta_data` | `object` | No | Free-form metadata persisted with the message. |

## Example request

<CodeGroup>

```bash curl
curl -X POST https://api.keebai.com/v1/messages/text \
  -H "Authorization: Bearer kbai_pk_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "to": "+5491155555555",
    "phone_number_id": "109876543210987",
    "text": "Hola Lucio, ¿pudiste revisar la propuesta?"
  }'
```

```js JavaScript
await fetch("https://api.keebai.com/v1/messages/text", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.KEEBAI_API_TOKEN}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    to: "+5491155555555",
    phone_number_id: "109876543210987",
    text: "Hola Lucio, ¿pudiste revisar la propuesta?",
  }),
});
```

```python Python
import os, requests

requests.post(
    "https://api.keebai.com/v1/messages/text",
    headers={"Authorization": f"Bearer {os.environ['KEEBAI_API_TOKEN']}"},
    json={
        "to": "+5491155555555",
        "phone_number_id": "109876543210987",
        "text": "Hola Lucio, ¿pudiste revisar la propuesta?",

    timeout=10,

```

## Response

### 202 Accepted

```json
{
  "broadcast_id": "65f4b5c6d7e8f9a0b1c2d3e4",
  "status": "PENDING",
  "total_recipients": 1,
  "scheduled_at": null
}
```

Same shape as [`POST /v1/messages/template`](/dev/endpoints/messages-template#202-accepted).

### 400 Bad Request

Invalid body (empty text, longer than 4096 characters, malformed phone number).

### 401 Unauthorized

Missing, invalid, revoked, or expired token.

### 403 Forbidden

The token does not have the `messages:send` scope.

## Operational notes

- **24-hour window**: Keebai does not reject the request if the window is closed — the send is attempted and, if Meta rejects it, the broadcast ends in `FAILED`. Check status with [`GET /v1/messages/bulk/:broadcastId`](/dev/endpoints/messages-bulk-status).
- **No special emoji handling**: WhatsApp supports full UTF-8, including emojis. Keebai performs no extra sanitization.
- **No native Markdown formatting**: WhatsApp interprets `*text*` as bold, `_text_` as italic, and `~text~` as strikethrough. A backslash escapes these characters.
