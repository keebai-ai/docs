Situations that can come up and how to answer each one. Unlike [steps](/dev/endpoints/blocks-create-steps), these have no order between them — the agent matches whichever applies.

The block is created in the project catalogue and is **not attached to anything**. Wire it into an agent with [`POST /v1/agents/{id}/blocks`](/dev/endpoints/agents-block-attach) afterwards.

<Note>
  **Instruction block: an agent can hold several.**
</Note>

## Endpoint

```
POST https://api.keebai.com/v1/blocks/cases-possible
```

## Required scope

`agents:write`

## Headers

| Header | Required | Value |
|---|---|---|
| `Authorization` | Yes | `Bearer kbai_pk_<token>` |
| `Content-Type` | Yes | `application/json` |

## Body

| Field | Type | Required | Description |
|---|---|---|---|
| `name` | `string` | Yes | Up to 150 characters. What the block shows as in the portal. |
| `content` | `string` | No | The block's text, up to 100,000 characters. Omit it to create an empty block. |

`type` and `family` are not accepted: the type is the endpoint you called, and `family` is derived from it (`instructions` for this one).

## Example request

<CodeGroup>

```bash curl
curl -X POST https://api.keebai.com/v1/blocks/cases-possible \
  -H "Authorization: Bearer kbai_pk_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Casos frecuentes",
    "content": "- Si el cliente pide un horario ya tomado, ofrecer los dos más cercanos.\n- Si pregunta por precios, dar el rango y aclarar que varía por profesional.\n- Si quiere cancelar, confirmar la reserva antes de cancelarla."
  }'
```

```js JavaScript
const resp = await fetch("https://api.keebai.com/v1/blocks/cases-possible", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.KEEBAI_API_TOKEN}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    name: "Casos frecuentes",
    content: "- Si el cliente pide un horario ya tomado, ofrecer los dos más cercanos.\n- Si pregunta por precios, dar el rango y aclarar que varía por profesional.\n- Si quiere cancelar, confirmar la reserva antes de cancelarla.",
  }),
});

const { block } = await resp.json();

// Then wire it into an agent.
await fetch("https://api.keebai.com/v1/agents/6650a1b2c3d4e5f6a7b8c9d0/blocks", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.KEEBAI_API_TOKEN}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({ block_id: block._id }),
});
```

```python Python
import os, requests

resp = requests.post(
    "https://api.keebai.com/v1/blocks/cases-possible",
    headers={"Authorization": f"Bearer {os.environ['KEEBAI_API_TOKEN']}"},
    json={"name": "Casos frecuentes", "content": "- Si el horario está tomado, ofrecer los dos más cercanos."},
    timeout=10,
)
resp.raise_for_status()
block = resp.json()["block"]
```

## Response

### 201 Created

```json
{
  "block": {
    "_id": "6650bbbb2222cccc3333dddd",
    "type": "cases_possible",
    "family": "instructions",
    "name": "Casos frecuentes",
    "current_version_id": "6650ffff4444aaaa5555bbbb",
    "is_archived": false,
    "content_writable": true,
    "created_at": "2026-07-26T21:38:22.104Z",
    "updated_at": "2026-07-26T21:38:22.104Z"
  }
}
```

### 400 Bad Request

Missing `name`, `content` over 100,000 characters, or a property the endpoint does not accept.

### 401 Unauthorized

Missing, invalid, revoked, or expired token.

### 403 Forbidden

The token does not have the `agents:write` scope.

### 502 Bad Gateway

The agent service is unreachable.

## Operational notes

- A case is a condition and an action. Writing them as "Si X, entonces Y" keeps them unambiguous when several could match at once.
- **Creating a block also creates its first version.** The response already carries a `current_version_id`, even when you omit `content` — the block starts with one empty version rather than none.
- **Creation is not idempotent.** Nothing enforces unique names, so a retry after a timeout leaves you with two blocks. Check [the catalogue](/dev/endpoints/blocks-list) filtered by `type` before retrying.
- **Content is plain text with three markdown conventions**: `-` for bullets, `1.` for numbered items, `#` for headings. Everything else is a paragraph. [More on how content is stored](/dev/agents/overview#content-is-text).
- **The block belongs to the token's project**, and a token on another project can neither see it nor read it by id.
