Sends a document to a recipient. Supply exactly one source: a public `link`, or a `media_id`.

Only works inside the **24-hour window** since the recipient's last inbound message.

## Endpoint

```
POST https://api.keebai.com/v1/messages/document
```

## Required scope

`messages:send`

## Headers

| Header | Required | Value |
|---|---|---|
| `Authorization` | Yes | `Bearer kbai_pk_<token>` |
| `Content-Type` | Yes | `application/json` |

## Body

| Field | Type | Required | Description |
|---|---|---|---|
| `to` | `string` | Yes | Recipient phone number in E.164 format. |
| `phone_number_id` | `string` | Yes | WhatsApp Business `phone_number_id` of the sending number. |
| `link` | `string` | No | Public HTTPS URL of the document. Mutually exclusive with `media_id`. |
| `media_id` | `string` | No | Id of a previously uploaded media. Mutually exclusive with `link`. |
| `filename` | `string` | No | Name the recipient sees and saves. Up to 240 characters. |
| `caption` | `string` | No | Text under the document. Up to 1024 characters. |
| `meta_data` | `object` | No | Free-form metadata persisted with the message. |

## Response

### 202 Accepted

```json
{
  "message_id": "wamid.HBgLNTQ5MTE1NTU1NTU1FQIAERgSN0EyRjc4...",
  "status": "sent",
  "sent_at": "2026-05-02T14:31:07.221Z"
}
```

### 400 Bad Request

A malformed phone number, a `link` that is not a valid HTTPS URL, a caption over 1024 characters, or an unknown property.

### 401 Unauthorized

Missing, invalid, revoked, or expired token.

### 403 Forbidden

The token does not have the `messages:send` scope.

## Operational notes

- **Always send `filename`.** Without it WhatsApp shows the last path segment of the URL, which is usually an opaque hash. Include the extension — the recipient's phone picks the app to open it by that.
- **Documents cap at 100 MB** at Meta, the most generous of any media type.
- **A `caption` and a `filename` are different things**: the caption is the message text, the filename is what the file is called once saved.
