Sends a message with a call-to-action button that opens a link. Unlike pasting a URL into a text message, the link is rendered as a proper button and WhatsApp does not show the raw address in the bubble.

Only works inside the **24-hour window** since the recipient's last inbound message.

## Endpoint

```
POST https://api.keebai.com/v1/messages/interactive/cta-url
```

## Required scope

`messages:send`

## Headers

| Header | Required | Value |
|---|---|---|
| `Authorization` | Yes | `Bearer kbai_pk_<token>` |
| `Content-Type` | Yes | `application/json` |

## Body

| Field | Type | Required | Description |
|---|---|---|---|
| `to` | `string` | Yes | Recipient phone number in E.164 format. |
| `phone_number_id` | `string` | Yes | WhatsApp Business `phone_number_id` of the sending number. |
| `body_text` | `string` | Yes | Message body. Up to 1024 characters. |
| `display_text` | `string` | Yes | Visible button label. Up to 20 characters. |
| `url` | `string` | Yes | Destination URL, including the scheme. |
| `header` | `object` | No | `{ "type": "text", "text": "..." }`. |
| `footer_text` | `string` | No | Up to 60 characters. |
| `meta_data` | `object` | No | Free-form metadata persisted with the message. |

## Response

### 202 Accepted

```json
{
  "message_id": "wamid.HBgLNTQ5MTE1NTU1NTU1FQIAERgSN0EyRjc4...",
  "status": "sent",
  "sent_at": "2026-05-02T14:31:07.221Z"
}
```

### 400 Bad Request

A `url` without a scheme, a `display_text` over 20 characters, a `body_text` over 1024, or an unknown property.

### 401 Unauthorized

Missing, invalid, revoked, or expired token.

### 403 Forbidden

The token does not have the `messages:send` scope.

## Operational notes

- **The URL must include the scheme.** `example.com/track` is rejected with `400`; `https://example.com/track` is fine.
- **There is exactly one button.** For several links, fall back to a text message with the URLs inline, or a [list](/dev/endpoints/messages-interactive-list) whose rows your handler maps to redirects.
- **Tapping produces no webhook.** Unlike quick reply buttons, opening a link is invisible to your backend — track it with a query parameter on the URL itself.
