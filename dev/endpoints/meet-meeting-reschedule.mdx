Moves a meeting to a new slot. Keebai checks the new slot, moves the calendar event (the guests get the update from their calendar), and schedules the reminders again for the new time. The reminders of the old time are never sent. The meeting ends in `rescheduled`.

## Endpoint

```
POST https://api.keebai.com/v1/meet/meetings/:id/reschedule
```

## Required scope

`meet:meetings:reschedule`

## Path params

| Param | Type | Description |
|---|---|---|
| `id` | `string` | Meeting id. |

## Body

| Field | Type | Required | Description |
|---|---|---|---|
| `start` | `string` | Yes | New start, ISO 8601 with `Z` or an offset. Take it from [availability](/dev/endpoints/meet-availability). |
| `host_user_id` | `string` | No | Move the meeting to this host too. |

## Response

### 200 OK

Returns [the meeting](/dev/endpoints/meet-meeting-get) with the new `start`, `end`, host, and reminders.

### 404 Not Found

| Code | When |
|---|---|
| `MEETING_NOT_FOUND` | The meeting does not exist or belongs to another company. |
| `MEETING_TYPE_NOT_FOUND` | The meeting type was deleted, so the meeting cannot be moved. Book a new one with another type. |

### 409 Conflict

| Code | When |
|---|---|
| `SLOT_NOT_AVAILABLE` | The new slot is taken. Query availability again. |
| `NO_HOST_AVAILABLE` | No host can take the new slot. |
| `MEETING_ALREADY_CANCELLED` | A cancelled meeting cannot be moved. Book a new one. |
| `MEETING_ALREADY_CLOSED` | The meeting was already marked `completed` or `no_show`. Book a new one. |

### 422 Unprocessable Entity

`HOST_CALENDAR_NOT_CONNECTED`: the host who would take the new slot has no calendar connected in Keebai. Someone on your team has to connect it under **Meet › People**.

### 400 Bad Request · 401 Unauthorized · 403 Forbidden

`400` for a `start` without a zone or a `host_user_id` that is not an ObjectId. The rest, same semantics as the rest of the public API.
