Sends a message with a button that opens the product catalog linked to your WhatsApp Business Account, so the recipient can browse and build a cart without leaving the chat.

This requires a catalog already configured in Meta Commerce Manager and connected to your WABA. Keebai does not manage catalogs.

Only works inside the **24-hour window** since the recipient's last inbound message.

## Endpoint

```
POST https://api.keebai.com/v1/messages/interactive/catalog
```

## Required scope

`messages:send`

## Headers

| Header | Required | Value |
|---|---|---|
| `Authorization` | Yes | `Bearer kbai_pk_<token>` |
| `Content-Type` | Yes | `application/json` |

## Body

| Field | Type | Required | Description |
|---|---|---|---|
| `to` | `string` | Yes | Recipient phone number in E.164 format. |
| `phone_number_id` | `string` | Yes | WhatsApp Business `phone_number_id` of the sending number. |
| `body_text` | `string` | Yes | Message body. Up to 1024 characters. |
| `thumbnail_product_retailer_id` | `string` | No | Retailer id of the product used as the cover image. Defaults to the first product in the catalog. |
| `footer_text` | `string` | No | Up to 60 characters. |
| `meta_data` | `object` | No | Free-form metadata persisted with the message. |

## Response

### 202 Accepted

```json
{
  "message_id": "wamid.HBgLNTQ5MTE1NTU1NTU1FQIAERgSN0EyRjc4...",
  "status": "sent",
  "sent_at": "2026-05-02T14:31:07.221Z"
}
```

### 400 Bad Request

A `body_text` over 1024 characters, a `footer_text` over 60, or an unknown property.

### 401 Unauthorized

Missing, invalid, revoked, or expired token.

### 403 Forbidden

The token does not have the `messages:send` scope.

### 502 Bad Gateway

Meta rejected the send. The usual cause is a WABA with no catalog attached, or a `thumbnail_product_retailer_id` that is not in it.

## Operational notes

- **`thumbnail_product_retailer_id` is your retailer SKU**, the id you set in Commerce Manager — not a Meta numeric id. A wrong value fails at Meta with `502`, not `400`.
- **The cart comes back as an order webhook.** When the recipient checks out, the `order` payload arrives on your [inbound webhook](/dev/webhooks/events); this endpoint has no way to read the cart itself.
- **Catalog messages are not available in every country.** Meta gates commerce features regionally; if the button never renders for a recipient, check their region before debugging the payload.
