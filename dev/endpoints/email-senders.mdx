Returns the senders that are ready to use. Pick one and pass its `email` as `from_email` (or its `channel_id`) in [`POST /v1/email/send`](/dev/endpoints/email-send), or let the send pick the default for you.

## Endpoint

```
GET https://api.keebai.com/v1/email/senders
```

## Required scope

`channels:read`

## Headers

| Header | Required | Value |
|---|---|---|
| `Authorization` | Yes | `Bearer kbai_pk_<token>` |

## Example request

<CodeGroup>

```bash curl
curl https://api.keebai.com/v1/email/senders \
  -H "Authorization: Bearer kbai_pk_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
```

```js JavaScript
const response = await fetch("https://api.keebai.com/v1/email/senders", {
  headers: { Authorization: `Bearer ${process.env.KEEBAI_API_TOKEN}` },
});
const { senders } = await response.json();
```

```python Python
import os, requests

resp = requests.get(
    "https://api.keebai.com/v1/email/senders",
    headers={"Authorization": f"Bearer {os.environ['KEEBAI_API_TOKEN']}"},
    timeout=10,
)
resp.raise_for_status()
senders = resp.json()["senders"]
```

</CodeGroup>

## Response

### 200 OK

```json
{
  "senders": [
    {
      "channel_id": "6650b1c2d3e4f5a6b7c8d9e0",
      "email": "hola@empresa.com",
      "name": "Empresa",
      "provider": "ses"
    },
    {
      "channel_id": "6650b1c2d3e4f5a6b7c8d9e1",
      "email": "ventas@empresa.com",
      "name": "Ventas Empresa",
      "provider": "gmail"
    }
  ]
}
```

| Field | Type | Description |
|---|---|---|
| `channel_id` | `string` | Keebai channel id of the sender. |
| `email` | `string` | Address the email goes out from. |
| `name` | `string` | Account name. It is the default sender name when the send does not pass `from_name`. |
| `provider` | `string` | `ses` (your own verified address), `gmail`, or `outlook`. |

### 401 Unauthorized

Missing, invalid, revoked, or expired token.

### 403 Forbidden

The token does not have the `channels:read` scope.

### 502 Bad Gateway

The messaging service could not answer.

## Operational notes

- **Only ready senders are listed.** An own address (`ses`) appears once its domain is verified. Until then it is not in the list and you cannot send from it.
- **An empty list means no email sender is connected.** Connect one in **Channels** in the Keebai portal. Sending without one fails with `EMAIL_SENDER_NOT_CONNECTED`.
- **The default sender is the own one.** When a send does not pick a sender, Keebai uses the verified `ses` address and, if there is none, the connected Gmail or Outlook mailbox.
