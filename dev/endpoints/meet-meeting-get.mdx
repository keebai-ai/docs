Returns one meeting, including the state of each of its reminders.

## Endpoint

```
GET https://api.keebai.com/v1/meet/meetings/:id
```

## Required scope

`meet:meetings:read`

## Path params

| Param | Type | Description |
|---|---|---|
| `id` | `string` | Meeting id. |

## Example request

<CodeGroup>

```bash curl
curl https://api.keebai.com/v1/meet/meetings/6735f1e2d3c4b5a697887766 \
  -H "Authorization: Bearer kbai_pk_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
```

```js JavaScript
const meeting = await (
  await fetch(`https://api.keebai.com/v1/meet/meetings/${meetingId}`, {
    headers: { Authorization: `Bearer ${process.env.KEEBAI_API_TOKEN}` },
  })
).json();
```

</CodeGroup>

| Field | Description |
|---|---|
| `status` | `scheduled`, `confirmed`, `rescheduled`, `cancelled`, `completed`, or `no_show`. |
| `source` | Who booked it: `agent` (a Keebai agent in a conversation), `manual` (your team in the portal), or `public` (this API). |
| `co_host_user_ids` | The other hosts who attend when the type is `collective`. Empty otherwise. |
| `created_by` | `kind` is `agent` or `user`, with its id and name. |
| `reminders[].audience` | `customer` (the customer) or `team` (the host). |
| `reminders[].channel` | `whatsapp` or `email` for the customer; `push` or `email` for the team. |
| `reminders[].status` | `scheduled`, `sent`, `failed`, or `skipped`. A `skipped` or `failed` reminder carries a `reason`. |
| `cancelled_at`, `cancel_reason` | Present once the meeting is cancelled. |

### 404 Not Found

`MEETING_NOT_FOUND`: the meeting does not exist or belongs to another company.

### 401 Unauthorized · 403 Forbidden

Same semantics as the rest of the public API.
