Sends a geographic location. The recipient sees a map preview they can tap to open in their maps app.

Only works inside the **24-hour window** since the recipient's last inbound message.

## Endpoint

```
POST https://api.keebai.com/v1/messages/location
```

## Required scope

`messages:send`

## Headers

| Header | Required | Value |
|---|---|---|
| `Authorization` | Yes | `Bearer kbai_pk_<token>` |
| `Content-Type` | Yes | `application/json` |

## Body

| Field | Type | Required | Description |
|---|---|---|---|
| `to` | `string` | Yes | Recipient phone number in E.164 format. |
| `phone_number_id` | `string` | Yes | WhatsApp Business `phone_number_id` of the sending number. |
| `latitude` | `number` | Yes | Between `-90` and `90`. |
| `longitude` | `number` | Yes | Between `-180` and `180`. |
| `name` | `string` | No | Name of the place. Up to 1000 characters. |
| `address` | `string` | No | Street address shown under the name. Up to 1000 characters. |
| `meta_data` | `object` | No | Free-form metadata persisted with the message. |

## Response

### 202 Accepted

```json
{
  "message_id": "wamid.HBgLNTQ5MTE1NTU1NTU1FQIAERgSN0EyRjc4...",
  "status": "sent",
  "sent_at": "2026-05-02T14:31:07.221Z"
}
```

### 400 Bad Request

A latitude outside `-90..90`, a longitude outside `-180..180`, a coordinate sent as a string instead of a number, or an unknown property.

### 401 Unauthorized

Missing, invalid, revoked, or expired token.

### 403 Forbidden

The token does not have the `messages:send` scope.

## Operational notes

- **Send coordinates as JSON numbers, not strings.** `"latitude": "-33.4489"` is rejected with `400`.
- **`name` without `address` renders oddly** on some clients — the pin shows a title with no subtitle. Send both or neither.
- **This is a static pin, not live location.** The WhatsApp Business API cannot send a moving location.
