Sends contact cards (vCards) to a recipient — the WhatsApp equivalent of forwarding someone's phone book entry.

<Note>
  This shares contact details **inside a conversation**. It does not create anything in Keebai. To create a contact record, use [`POST /v1/contacts`](/dev/endpoints/contacts-create).
</Note>

Only works inside the **24-hour window** since the recipient's last inbound message.

## Endpoint

```
POST https://api.keebai.com/v1/messages/contacts
```

## Required scope

`messages:send`

## Headers

| Header | Required | Value |
|---|---|---|
| `Authorization` | Yes | `Bearer kbai_pk_<token>` |
| `Content-Type` | Yes | `application/json` |

## Body

| Field | Type | Required | Description |
|---|---|---|---|
| `to` | `string` | Yes | Recipient phone number in E.164 format. |
| `phone_number_id` | `string` | Yes | WhatsApp Business `phone_number_id` of the sending number. |
| `contacts` | `array` | Yes | 1 to 20 contact cards. |
| `meta_data` | `object` | No | Free-form metadata persisted with the message. |

Each entry in `contacts`:

| Field | Type | Required | Description |
|---|---|---|---|
| `name` | `object` | Yes | `{ "formatted_name": "...", "first_name": "...", "last_name": "..." }`. `formatted_name` is mandatory. |
| `phones` | `array` | No | `[{ "phone": "+56...", "type": "WORK", "wa_id": "56..." }]`. |
| `emails` | `array` | No | `[{ "email": "...", "type": "WORK" }]`. |
| `urls` | `array` | No | `[{ "url": "https://...", "type": "WORK" }]`. |
| `org` | `object` | No | `{ "company": "...", "department": "...", "title": "..." }`. |
| `birthday` | `string` | No | `YYYY-MM-DD`. |

## Response

### 202 Accepted

```json
{
  "message_id": "wamid.HBgLNTQ5MTE1NTU1NTU1FQIAERgSN0EyRjc4...",
  "status": "sent",
  "sent_at": "2026-05-02T14:31:07.221Z"
}
```

### 400 Bad Request

An empty `contacts` array, more than 20 entries, a card without `name.formatted_name`, or an unknown property.

### 401 Unauthorized

Missing, invalid, revoked, or expired token.

### 403 Forbidden

The token does not have the `messages:send` scope.

## Operational notes

- **`wa_id` is what makes the card actionable.** Without it the recipient sees a phone number they must copy; with it, WhatsApp offers a "Message" button. It is the phone number without the `+`.
- **`name.formatted_name` is the only mandatory field of a card** — everything else is optional decoration.
- **All 20 cards arrive as one message**, not twenty.
