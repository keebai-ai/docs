Returns one tag of your company.

## Endpoint

```
GET https://api.keebai.com/v1/crm/tags/{id}
```

## Required scope

`crm:tags:read`

## Headers

| Header | Required | Value |
|---|---|---|
| `Authorization` | Yes | `Bearer kbai_pk_<token>` |

## Path parameters

| Field | Type | Required | Description |
|---|---|---|---|
| `id` | `string` | Yes | `ObjectId` of the tag. |

## Example request

<CodeGroup>

```bash curl
curl https://api.keebai.com/v1/crm/tags/6720a1b2c3d4e5f6a7b8c9d0 \
  -H "Authorization: Bearer kbai_pk_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
```

```js JavaScript
const response = await fetch(`https://api.keebai.com/v1/crm/tags/${tagId}`, {
  headers: { Authorization: `Bearer ${process.env.KEEBAI_API_TOKEN}` },
});
const { tag } = await response.json();
```

```python Python
import os, requests

resp = requests.get(
    f"https://api.keebai.com/v1/crm/tags/{tag_id}",
    headers={"Authorization": f"Bearer {os.environ['KEEBAI_API_TOKEN']}"},
    timeout=10,
)
resp.raise_for_status()
tag = resp.json()["tag"]
```

</CodeGroup>

## Response

### 200 OK

```json
{
  "tag": {
    "_id": "6720a1b2c3d4e5f6a7b8c9d0",
    "name": "Cliente VIP",
    "color": "#f5a623",
    "scope": "ticket",
    "category_id": "6720a0f1e2d3c4b5a6978877",
    "created_at": "2026-10-02T13:04:11.512Z",
    "updated_at": "2026-10-02T13:04:11.512Z"
  }
}
```

`category_id` is `null` for a tag without a category. The detail does not include the `category` summary; [list the categories](/dev/endpoints/crm-tag-categories-list) to resolve it.

### 401 Unauthorized

Missing, invalid, revoked, or expired token.

### 403 Forbidden

The token does not have the `crm:tags:read` scope.

### 404 Not Found

No tag with that id, the id is not a valid `ObjectId`, or the tag belongs to a different company.
