Books a meeting. Keebai checks the slot again, assigns the host, creates the event on the host's calendar with the video link, invites the customer and the guests, schedules the [reminders](/dev/meet/overview#reminders), and adds the meeting to the CRM timeline when you pass a `chat_user_id` or `ticket_id` and the contact has an open ticket.

The meeting is recorded with `source: "public"` and `created_by` set to the owner of the token. You never send either one.

## Endpoint

```
POST https://api.keebai.com/v1/meet/meetings
```

## Required scope

`meet:meetings:create`

## Headers

| Header | Required | Value |
|---|---|---|
| `Authorization` | Yes | `Bearer kbai_pk_<token>` |
| `Content-Type` | Yes | `application/json` |
| `Idempotency-Key` | Yes | Up to 128 letters, digits, `-` or `_`. A retry with the same key and body returns the meeting already booked. |

## Body

| Field | Type | Required | Description |
|---|---|---|---|
| `type_id` | `string` | Yes | Meeting type. |
| `start` | `string` | Yes | Slot start, ISO 8601 with `Z` or an offset. Use a `start` from [availability](/dev/endpoints/meet-availability) unchanged. |
| `host_user_id` | `string` | No | Pin a host. Omit it and the type's assignment picks one. |
| `customer.name` | `string` | Yes | Customer name, shown in the invitation (max 120). |
| `customer.email` | `string` | No | Receives the calendar invitation and email reminders. |
| `customer.phone` | `string` | No | International format, such as `+56912345678`. Used for WhatsApp reminders. |
| `customer.chat_user_id` | `string` | No | The customer's chat in Keebai. |
| `customer.customer_id` | `string` | No | The CRM customer. |
| `customer.ticket_id` | `string` | No | CRM ticket whose timeline gets the meeting. |
| `invitee_emails` | `string[]` | No | Extra guests' emails, at most 20, without repeats. |

### 400 Bad Request

A missing or invalid `Idempotency-Key` (`IDEMPOTENCY_KEY_REQUIRED`), a `start` without a zone, a field that is not an ObjectId, or fields the API does not accept, such as `company`, `source`, or `created_by`.

### 404 Not Found

`MEETING_TYPE_NOT_FOUND`: the type does not exist in your company.

### 409 Conflict

```json
{
  "error": {
    "code": "SLOT_NOT_AVAILABLE",
    "message": "El horario ya no está disponible."
  }
}
```

| Code | What to do |
|---|---|
| `SLOT_NOT_AVAILABLE` | Someone took the slot. Query availability again and offer the new options. |
| `NO_HOST_AVAILABLE` | No host can take that slot. Offer another one. |
| `IDEMPOTENCY_KEY_IN_PROGRESS` | The first request with this `Idempotency-Key` is still running. Wait a moment and retry with the same key and body: you get that booking, not a second one. |
| `IDEMPOTENCY_KEY_MISMATCH` | The `Idempotency-Key` was already used with a different body. Use a new key for a different booking. |

### 422 Unprocessable Entity

`HOST_CALENDAR_NOT_CONNECTED`: the host has no calendar connected in Keebai, so the event cannot be created. Someone on your team has to connect it under **Meet › People**.

### 503 Service Unavailable

Retryable: the response carries `error.details.retryable: true` and nothing was written. Retry in a few seconds with the same slot and the same `Idempotency-Key`.

| Code | When |
|---|---|
| `MEETING_LOCK_UNAVAILABLE` | Another booking or change for the same host is in progress. |
| `HOST_CALENDAR_UNAVAILABLE` | The host's calendar is connected but could not be read right now. This is not `HOST_CALENDAR_NOT_CONNECTED`, and it does not mean the slot is taken. |

### 401 Unauthorized · 403 Forbidden

Same semantics as the rest of the public API.
