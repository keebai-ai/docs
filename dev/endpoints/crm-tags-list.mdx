Returns a paginated list of the tags defined in your company, sorted by name. Results cover the whole **company**, not just the project your token belongs to — see [Tenancy is implicit](/dev/crm/overview#tenancy-is-implicit).

Every tag has a **scope**: `ticket` tags label pipeline tickets, and `client` tags label customers and contacts. A tag's `_id` is what you send in a customer's `tags` array or in a [ticket update](/dev/endpoints/crm-ticket-update)'s `tag_ids`, `add_tag_ids`, and `remove_tag_ids`.

## Endpoint

```
GET https://api.keebai.com/v1/crm/tags
```

## Required scope

`crm:tags:read`

## Headers

| Header | Required | Value |
|---|---|---|
| `Authorization` | Yes | `Bearer kbai_pk_<token>` |

## Query parameters

| Field | Type | Required | Description |
|---|---|---|---|
| `scope` | `string` | No | `ticket` or `client`. |
| `search` | `string` | No | Case-insensitive match anywhere in the tag name. Up to 100 characters. |
| `category_id` | `string` | No | `ObjectId` of a [tag category](/dev/endpoints/crm-tag-categories-list). Only tags in that category. |
| `limit` | `integer` | No | Page size, `1`–`200`. Defaults to 50. |
| `offset` | `integer` | No | Records to skip. Defaults to 0. |

## Example request

<CodeGroup>

```bash curl
curl -G https://api.keebai.com/v1/crm/tags \
  -H "Authorization: Bearer kbai_pk_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx" \
  --data-urlencode "scope=ticket" \
  --data-urlencode "search=vip"
```

```js JavaScript
const params = new URLSearchParams({ scope: "ticket", search: "vip" });

const response = await fetch(`https://api.keebai.com/v1/crm/tags?${params}`, {
  headers: { Authorization: `Bearer ${process.env.KEEBAI_API_TOKEN}` },
});
const { data, total } = await response.json();
```

```python Python
import os, requests

resp = requests.get(
    "https://api.keebai.com/v1/crm/tags",
    headers={"Authorization": f"Bearer {os.environ['KEEBAI_API_TOKEN']}"},
    params={"scope": "ticket", "search": "vip"},
    timeout=10,
)
resp.raise_for_status()
tags = resp.json()["data"]
```

## Response

### 200 OK

```json
{

    {
      "_id": "6720a1b2c3d4e5f6a7b8c9d0",
      "name": "Cliente VIP",
      "color": "#f5a623",
      "scope": "ticket",
      "category_id": "6720a0f1e2d3c4b5a6978877",
      "category": {
        "id": "6720a0f1e2d3c4b5a6978877",
        "name": "Segmento",
        "exclusive": true
      },
      "created_at": "2026-10-02T13:04:11.512Z",
      "updated_at": "2026-10-02T13:04:11.512Z"
    }
  ],
  "total": 1,
  "limit": 50,
  "offset": 0
}
```

`category` is `null` for a tag without a category.

### 400 Bad Request

A `scope` outside the allowed set, a malformed `category_id`, `limit` above 200, or an unknown query parameter.

### 401 Unauthorized

Missing, invalid, revoked, or expired token.

### 403 Forbidden

The token does not have the `crm:tags:read` scope.

## Operational notes

- **The catalog is small.** Most companies have a few dozen tags. Fetch it once, cache it, and resolve tag ids on tickets and customers locally instead of calling [GET /v1/crm/tags/:id](/dev/endpoints/crm-tag-get) per record.
- **Only the list resolves the category.** The detail and the write endpoints return `category_id` without the `category` summary.
