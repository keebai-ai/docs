Updates a tag in place. Tickets and customers reference tags by id, so a rename shows up everywhere the tag is applied. The `scope` cannot change.

## Endpoint

```
PATCH https://api.keebai.com/v1/crm/tags/{id}
```

## Required scope

`crm:tags:write`

## Headers

| Header | Required | Value |
|---|---|---|
| `Authorization` | Yes | `Bearer kbai_pk_<token>` |
| `Content-Type` | Yes | `application/json` |

## Path parameters

| Field | Type | Required | Description |
|---|---|---|---|
| `id` | `string` | Yes | `ObjectId` of the tag. |

## Body

All fields optional. Send only what changes.

| Field | Type | Description |
|---|---|---|
| `name` | `string` | New name. Up to 100 characters. Unique per scope within the company. |
| `color` | `string` | Hex color. |
| `category_id` | `string` \| `null` | `ObjectId` of a category of the same scope. Send `null` to remove the tag from its category. |

## Example request

<CodeGroup>

```bash curl
curl -X PATCH https://api.keebai.com/v1/crm/tags/6720a1b2c3d4e5f6a7b8c9d0 \
  -H "Authorization: Bearer kbai_pk_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{ "name": "VIP", "category_id": null }'
```

```js JavaScript
const response = await fetch(`https://api.keebai.com/v1/crm/tags/${tagId}`, {
  method: "PATCH",
  headers: {
    Authorization: `Bearer ${process.env.KEEBAI_API_TOKEN}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({ name: "VIP", category_id: null }),
});
const { tag } = await response.json();
```

```python Python
import os, requests

resp = requests.patch(
    f"https://api.keebai.com/v1/crm/tags/{tag_id}",
    headers={"Authorization": f"Bearer {os.environ['KEEBAI_API_TOKEN']}"},
    json={"name": "VIP", "category_id": None},
    timeout=10,
)
resp.raise_for_status()
tag = resp.json()["tag"]
```

## Response

### 200 OK

```json
{
  "tag": {
    "_id": "6720a1b2c3d4e5f6a7b8c9d0",
    "name": "VIP",
    "color": "#f5a623",
    "scope": "ticket",
    "category_id": null,
    "created_at": "2026-10-02T13:04:11.512Z",
    "updated_at": "2026-11-18T15:22:40.031Z"
  }
}
```

### 400 Bad Request

- Another tag of the same scope already has that `name` (`Tag name already exists for this scope`).
- The category belongs to the other scope (`Tag scope must match its category scope`).
- An empty `name`, a malformed `category_id`, or a property the endpoint does not accept — including `scope`.

### 401 Unauthorized

Missing, invalid, revoked, or expired token.

### 403 Forbidden

The token does not have the `crm:tags:write` scope.

### 404 Not Found

No tag with that id in your company (`Tag not found`), or `category_id` does not match a category of your company (`Tag category not found`).
