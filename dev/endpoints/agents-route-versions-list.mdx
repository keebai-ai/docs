The versions of a route, newest first, each with the content it held. One is written on every save that changes the content.

## Endpoint

```
GET https://api.keebai.com/v1/agents/{id}/routes/{routeId}/versions
```

## Required scope

`agents:read`

## Path parameters

| Parameter | Type | Description |
|---|---|---|
| `id` | `string` | `ObjectId` of the agent. |
| `routeId` | `string` | `ObjectId` of the route. |

## Example request

```bash curl
curl -X GET https://api.keebai.com/v1/agents/6650a1b2c3d4e5f6a7b8c9d0/routes/6652c0ffee11223344556688/versions \
  -H "Authorization: Bearer kbai_pk_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
```

### 400 Bad Request

`routeId` is not an `ObjectId`.

### 404 Not Found

No agent, scenario or route with those ids (`route_not_found`).
### 401 Unauthorized

Missing, invalid, revoked, or expired token.

### 403 Forbidden

The token does not have the `agents:read` scope.

### 502 Bad Gateway

The agent service is unreachable.

## Operational notes

- **Saving without changing the content does not add a version.**
