Resolves what a cashier scans or types into the product and variant it belongs to. An exact SKU or barcode returns those matches; anything else runs a text search over the catalog.

This is the lookup to run before [adjusting stock](/dev/endpoints/ecommerce-stock-adjust) or [creating a sale](/dev/endpoints/ecommerce-sales-create), since both take a `product_id` and, on products with variants, a `variant_id`.

## Endpoint

```
GET https://api.keebai.com/v1/ecommerce/products/find
```

## Required scope

`ecommerce:products:read`

## Headers

| Header | Required | Value |
|---|---|---|
| `Authorization` | Yes | `Bearer kbai_pk_<token>` |

## Query parameters

| Field | Type | Required | Description |
|---|---|---|---|
| `query` | `string` | Yes | SKU, barcode, or free text. |
| `limit` | `integer` | No | Maximum number of items, `1`–`50`. Defaults to 10. |

## Example request

<CodeGroup>

```bash curl
curl -G https://api.keebai.com/v1/ecommerce/products/find \
  -H "Authorization: Bearer kbai_pk_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx" \
  --data-urlencode "query=7801234567890"
```

```js JavaScript
const params = new URLSearchParams({ query: "7801234567890" });

const response = await fetch(
  `https://api.keebai.com/v1/ecommerce/products/find?${params}`,
  { headers: { Authorization: `Bearer ${process.env.KEEBAI_API_TOKEN}` } },
);
const { match, items } = await response.json();
```

```python Python
import os, requests

resp = requests.get(
    "https://api.keebai.com/v1/ecommerce/products/find",
    headers={"Authorization": f"Bearer {os.environ['KEEBAI_API_TOKEN']}"},
    params={"query": "7801234567890"},
    timeout=10,
)
resp.raise_for_status()
result = resp.json()
```

</CodeGroup>

## Response

### 200 OK

```json
{
  "match": "exact",
  "items": [
    {
      "product_id": "65d3e4f5a6b7c8d9e0f1a2b3",
      "variant_id": "65d3e4f5a6b7c8d9e0f1a2c1",
      "name": "Zapatilla Runner Pro",
      "variant_name": "42 / Negro",
      "sku": "RUN-PRO-42-NEG",
      "barcode": "7801234567890",
      "price": 59990,
      "stock_total": 12
    }
  ]
}
```

| Field | Type | Description |
|---|---|---|
| `match` | `string` | `exact` when `query` matched a SKU or barcode exactly; `search` when the result comes from a text search. |
| `items[].product_id` | `string` | `ObjectId` of the product. |
| `items[].variant_id` | `string` | `ObjectId` of the variant, when the match is a variant. |
| `items[].name` | `string` | Product name. |
| `items[].variant_name` | `string` | Variant name, when the match is a variant. |
| `items[].sku` | `string` | SKU. |
| `items[].barcode` | `string \| null` | Barcode of the variant. `null` on a product-level item, since barcodes live on variants. |
| `items[].price` | `number` | Price. |
| `items[].stock_total` | `number` | Master stock. See [`GET /v1/ecommerce/products/{id}/stock`](/dev/endpoints/ecommerce-product-stock) for the split by branch. |

### 401 Unauthorized

Missing, invalid, revoked, or expired token.

### 403 Forbidden

The token does not have the `ecommerce:products:read` scope.

### 502 Bad Gateway

`ECOMMERCE_UPSTREAM_ERROR` — the ecommerce service could not answer.

## Operational notes

- **SKU and barcode match loosely.** Case and spaces are ignored, so `run-pro-42-neg` finds `RUN-PRO-42-NEG`.
- **Branch on `match`.** With `exact` you can act on the item directly. With `search`, the items are candidates: show them to a person, or pick one only when there is a single clear result.
