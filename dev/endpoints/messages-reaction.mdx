Attaches an emoji reaction to a message the recipient can see. Sending an empty `emoji` removes a reaction you sent earlier.

You need the Meta `message_id` (`wamid.*`) of the target message — it arrives in the [inbound message webhook](/dev/webhooks/events).

## Endpoint

```
POST https://api.keebai.com/v1/messages/reaction
```

## Required scope

`messages:send`

## Headers

| Header | Required | Value |
|---|---|---|
| `Authorization` | Yes | `Bearer kbai_pk_<token>` |
| `Content-Type` | Yes | `application/json` |

## Body

| Field | Type | Required | Description |
|---|---|---|---|
| `to` | `string` | Yes | Recipient phone number in E.164 format. |
| `phone_number_id` | `string` | Yes | WhatsApp Business `phone_number_id` of the sending number. |
| `message_id` | `string` | Yes | Meta `message_id` (`wamid.*`) of the message to react to. |
| `emoji` | `string` | Yes | A single emoji, up to 8 characters. An empty string clears the reaction. |
| `meta_data` | `object` | No | Free-form metadata persisted with the message. |

## Response

### 202 Accepted

```json
{
  "message_id": "wamid.HBgLNTQ5MTE1NTU1NTU1FQIAERgSN0EyRjc5...",
  "status": "sent",
  "sent_at": "2026-05-02T14:31:07.221Z"
}
```

The returned `message_id` is the reaction's own id, not the id of the message you reacted to.

### 400 Bad Request

A missing `message_id`, an `emoji` longer than 8 characters, or an unknown property.

### 401 Unauthorized

Missing, invalid, revoked, or expired token.

### 403 Forbidden

The token does not have the `messages:send` scope.

## Operational notes

- **One reaction per message per sender.** Reacting again replaces the previous emoji rather than adding a second one.
- **Send `""` to clear.** There is no `DELETE` for reactions.
- **8 characters, not 8 emoji.** Compound emoji built with zero-width joiners (👨‍👩‍👧) burn several code points, so some valid single emoji do not fit.
- **A stale `message_id` fails at Meta**, not at Keebai — the request is accepted and then rejected upstream.
