Returns the DTE types your company can issue right now. A type is listed only when the issuer is active, its certificate is installed, and it has folios left for that type.

Read it before offering a boleta or a factura at your point of sale, so you never send a `dte.type` the company cannot issue.

## Endpoint

```
GET https://api.keebai.com/v1/ecommerce/invoicing/types
```

## Required scope

`ecommerce:invoicing:read`

## Headers

| Header | Required | Value |
|---|---|---|
| `Authorization` | Yes | `Bearer kbai_pk_<token>` |

## Example request

<CodeGroup>

```bash curl
curl https://api.keebai.com/v1/ecommerce/invoicing/types \
  -H "Authorization: Bearer kbai_pk_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
```

```js JavaScript
const response = await fetch("https://api.keebai.com/v1/ecommerce/invoicing/types", {
  headers: { Authorization: `Bearer ${process.env.KEEBAI_API_TOKEN}` },

const { types, env } = await response.json();
```

```python Python
import os, requests

resp = requests.get(
    "https://api.keebai.com/v1/ecommerce/invoicing/types",
    headers={"Authorization": f"Bearer {os.environ['KEEBAI_API_TOKEN']}"},
    timeout=10,
)
resp.raise_for_status()
types = resp.json()["types"]
```

</CodeGroup>

## Response

### 200 OK

```json
{
  "types": [39, 33],
  "env": "prod"
}
```

| Field | Type | Description |
|---|---|---|
| `types` | `number[]` | DTE types the company can issue today. See the table below. |
| `env` | `string \| null` | `prod` or `cert` (the tax authority's certification environment). `null` when no type can be issued. |

### DTE types

| `type` | Document |
|---|---|
| `39` | Boleta electrónica |
| `41` | Boleta exenta electrónica |
| `33` | Factura electrónica |
| `34` | Factura exenta electrónica |

### 401 Unauthorized

Missing, invalid, revoked, or expired token.

### 403 Forbidden

The token does not have the `ecommerce:invoicing:read` scope.

### 502 Bad Gateway

`ECOMMERCE_UPSTREAM_ERROR` — the ecommerce service could not answer.

## Operational notes

- **An empty list means the company cannot issue.** The issuer is not configured or active, the certificate is missing, or the folios ran out. That is fixed in the portal, not through this API.
- **A type can drop out of the list.** When the folios of a type run out, it stops appearing until more are loaded. Read the list again instead of caching it for days.
