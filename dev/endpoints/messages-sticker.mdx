Sends a sticker to a recipient. Supply exactly one source: a public `link`, or a `media_id`.

Only works inside the **24-hour window** since the recipient's last inbound message.

## Endpoint

```
POST https://api.keebai.com/v1/messages/sticker
```

## Required scope

`messages:send`

## Headers

| Header | Required | Value |
|---|---|---|
| `Authorization` | Yes | `Bearer kbai_pk_<token>` |
| `Content-Type` | Yes | `application/json` |

## Body

| Field | Type | Required | Description |
|---|---|---|---|
| `to` | `string` | Yes | Recipient phone number in E.164 format. |
| `phone_number_id` | `string` | Yes | WhatsApp Business `phone_number_id` of the sending number. |
| `link` | `string` | No | Public HTTPS URL of the `.webp` sticker. Mutually exclusive with `media_id`. |
| `media_id` | `string` | No | Id of a previously uploaded media. Mutually exclusive with `link`. |
| `meta_data` | `object` | No | Free-form metadata persisted with the message. |

Stickers take no caption.

## Example request

<CodeGroup>

```bash curl
curl -X POST https://api.keebai.com/v1/messages/sticker \
  -H "Authorization: Bearer kbai_pk_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "to": "+5491155555555",
    "phone_number_id": "109876543210987",
    "link": "https://cdn.example.com/stickers/thumbs-up.webp"
  }'
```

```js JavaScript
await fetch("https://api.keebai.com/v1/messages/sticker", {
  method: "POST",

```

```python Python
import os, requests

resp = requests.post(
    "https://api.keebai.com/v1/messages/sticker",
    headers={"Authorization": f"Bearer {os.environ['KEEBAI_API_TOKEN']}"},
    json={
        "to": "+5491155555555",

    },
    timeout=10,

resp.raise_for_status()
```

## Response

### 202 Accepted

```json
{
  "message_id": "wamid.HBgLNTQ5MTE1NTU1NTU1FQIAERgSN0EyRjc4...",
  "status": "sent",
  "sent_at": "2026-05-02T14:31:07.221Z"
}
```

### 400 Bad Request

A malformed phone number, a `link` that is not a valid HTTPS URL, or an unknown property.

### 401 Unauthorized

Missing, invalid, revoked, or expired token.

### 403 Forbidden

The token does not have the `messages:send` scope.

## Operational notes

- **WebP only, and the size limits are strict**: 100 KB for a static sticker, 500 KB for an animated one. A PNG renamed to `.webp` is rejected by Meta.
- **Stickers must be 512×512.** Meta does not resize; a wrongly sized image fails the send.
