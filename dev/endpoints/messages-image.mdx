Sends an image to a recipient. Supply exactly one source: a public `link`, or a `media_id` you got from [`POST /v1/media/upload`](/dev/messaging/overview).

Like every free-form message, this only works inside the **24-hour window** since the recipient's last inbound message. Outside it, use [`POST /v1/messages/template`](/dev/endpoints/messages-template).

## Endpoint

```
POST https://api.keebai.com/v1/messages/image
```

## Required scope

`messages:send`

## Headers

| Header | Required | Value |
|---|---|---|
| `Authorization` | Yes | `Bearer kbai_pk_<token>` |
| `Content-Type` | Yes | `application/json` |

## Body

| Field | Type | Required | Description |
|---|---|---|---|
| `to` | `string` | Yes | Recipient phone number in E.164 format. |
| `phone_number_id` | `string` | Yes | WhatsApp Business `phone_number_id` of the sending number. List yours with [`GET /v1/whatsapp/numbers`](/dev/endpoints/whatsapp-numbers). |
| `link` | `string` | No | Public HTTPS URL of the image. Mutually exclusive with `media_id`. |
| `media_id` | `string` | No | Id of a previously uploaded media. Mutually exclusive with `link`. |
| `caption` | `string` | No | Text under the image. Up to 1024 characters. |
| `meta_data` | `object` | No | Free-form metadata persisted with the message and echoed on webhooks. |

## Response

### 202 Accepted

```json
{
  "message_id": "wamid.HBgLNTQ5MTE1NTU1NTU1FQIAERgSN0EyRjc4...",
  "status": "sent",
  "sent_at": "2026-05-02T14:31:07.221Z"
}
```

### 400 Bad Request

A malformed phone number, a `link` that is not a valid HTTPS URL, a caption over 1024 characters, or an unknown property.

### 401 Unauthorized

Missing, invalid, revoked, or expired token.

### 403 Forbidden

The token does not have the `messages:send` scope.

## Operational notes

- **`link` must be publicly reachable from Meta's servers.** A signed URL that expires, or one behind your VPN, fails at Meta rather than at Keebai. If in doubt, upload the file and use `media_id`.
- **Supported formats are Meta's**: JPEG and PNG, up to 5 MB. Anything else is rejected upstream.
- **`media_id` is per sending number.** A media uploaded against one `phone_number_id` cannot be sent from another.
