El SDK oficial de Keebai para Node.js / TypeScript / runtimes modernos. Te ahorra escribir tu propia capa HTTP contra Meta Graph API o contra `api.keebai.com/v1`.

```ts
import { WhatsAppClient } from "@keebai/sdk";

const wa = new WhatsAppClient({
  apiKey: process.env.KEEBAI_API_KEY!,        // kbai_pk_<hex64>
  phoneNumberId: process.env.KEEBAI_PHONE_NUMBER_ID!,
});

await wa.messages.sendText({
  to: "+5491155555555",
  body: "Hola desde Keebai",
});
```

Eso es todo.

## Instalación

```bash
npm install @keebai/sdk
# o
pnpm add @keebai/sdk
# o
yarn add @keebai/sdk
```

Requiere Node.js 20+ (usa `fetch`, `FormData` y `Blob` globales). Funciona también en runtimes edge (Vercel Edge, Cloudflare Workers, Deno, Bun) y en navegadores modernos.

## Configuración

Setear credenciales por variables de entorno:

```bash
export KEEBAI_API_KEY=kbai_pk_<hex64>        # desde app.keebai.com → System Settings → API Keys
export KEEBAI_PHONE_NUMBER_ID=<numeric>       # phone_number_id del canal WhatsApp Cloud API
export KEEBAI_BASE_URL=https://api.keebai.com/v1   # opcional; default
```

Instanciar el cliente:

```ts
import { WhatsAppClient } from "@keebai/sdk";

const wa = new WhatsAppClient({
  apiKey: process.env.KEEBAI_API_KEY!,
  phoneNumberId: process.env.KEEBAI_PHONE_NUMBER_ID!,
});
```

## Los dos modos

| Modo | Credencial | Backend | Cuándo |
|---|---|---|---|
| `keebai` *(default)* | `apiKey: kbai_pk_...` | `https://api.keebai.com/v1` | Estás sobre la plataforma Keebai. Persistencia, multi-tenant, broadcasts, webhooks, dashboards. |
| `meta` | `accessToken: EAA...` | `https://graph.facebook.com/v21.0` | Tenés tu propia WhatsApp Business Account y querés ir directo a Meta. |

El cliente infiere el modo según la credencial. Mismos nombres de método, mismos tipos de retorno, mismo modelo de errores — solo cambia el transporte.

```ts
// Meta directo
const wa = new WhatsAppClient({
  accessToken: process.env.META_ACCESS_TOKEN!,
  phoneNumberId: process.env.META_PHONE_NUMBER_ID!,
});
```

Detalle de trade-offs en [Modo Meta directo](#modo-meta-directo).

## Superficie de la API

### `client.messages.*`

| Método | Para qué |
|---|---|
| `sendText` | Texto libre dentro de la ventana de 24h. |
| `sendImage` | JPG/PNG por URL o `media_id`. Opcional caption. |
| `sendVideo` | MP4 con caption opcional. |
| `sendAudio` | Audio. `voice: true` para PTT (Opus en OGG). |
| `sendDocument` | PDF/DOCX/etc. con filename y caption. |
| `sendSticker` | WebP estático o animado. |
| `sendLocation` | Pin geográfico con name y address opcionales. |
| `sendContacts` | Una o más vCards. |
| `sendReaction` | Emoji sobre un mensaje previo. |
| `markRead` | Marcar como leído, con typing indicator opcional. |
| `sendInteractiveButtons` | Hasta 3 reply buttons. |
| `sendInteractiveList` | Lista scrollable con secciones. |
| `sendInteractiveCtaUrl` | Botón único con URL externa. |
| `sendInteractiveCatalogMessage` | Mensaje de catálogo (Commerce). |
| `sendTemplate` | Template aprobado con variables nombradas. |
| `sendBulk` | Difusión masiva (Keebai mode). |
| `getBulkStatus` | Estado de una difusión previa (Keebai mode). |
| `sendRaw` | Escape hatch — body crudo de Graph API. |

### `client.media.*`

| Método | Para qué |
|---|---|
| `upload` | Subir un archivo. Devuelve `media_id` reusable. |
| `get` | Metadata (mime, size, sha256, URL firmada). |
| `delete` | Borrar un media subido. |
| `download` | Bajar el binario (`as: 'blob' \| 'arraybuffer'`). |

### `client.templates.*` *(Keebai mode)*

| Método | Para qué |
|---|---|
| `list` | Listar templates aprobados. |
| `create` | Crear y enviar a Meta para aprobación. |
| `update` | Editar componentes o categoría. |

## Ejemplos

### Enviar imagen con caption

```ts
await wa.messages.sendImage({
  to: "+5491155555555",
  image: {
    link: "https://cdn.example.com/banner.png",
    caption: "Nueva colección",
  },
});
```

### Template con variables nombradas

```ts
await wa.messages.sendTemplate({
  to: "+5491155555555",
  templateName: "order_confirmation",
  language: "es",
  variables: {
    nombre: "Lucio",
    pedido: "ORD-1234",
    monto: "$15.000",
  },
});
```

### Interactive buttons

```ts
await wa.messages.sendInteractiveButtons({
  to: "+5491155555555",
  bodyText: "¿Confirmás tu pedido?",
  buttons: [
    { id: "confirm", title: "Confirmar" },
    { id: "cancel", title: "Cancelar" },
  ],
});
```

### Subir media una vez, enviar N veces

```ts
import { readFile } from "node:fs/promises";

const buffer = await readFile("logo.png");
const file = new Blob([buffer], { type: "image/png" });

const { id: mediaId } = await wa.media.upload({
  file,
  fileName: "logo.png",
  type: "image/png",
});

for (const phone of recipients) {
  await wa.messages.sendImage({
    to: phone,
    image: { id: mediaId, caption: "Logo Keebai" },
  });
}
```

### Marcar como leído + typing

```ts
await wa.messages.markRead({
  messageId: "wamid.HBgL...",
  typingIndicator: "text",
});
```

### Difusión masiva

```ts
const { broadcastId } = await wa.messages.sendBulk({
  templateName: "march_promo",
  language: "es",
  campaignName: "March 2026",
  recipients: [
    { to: "+5491155555555", variables: { nombre: "Lucio" } },
    { to: "+5491166666666", variables: { nombre: "Ana" } },
  ],
});

const status = await wa.messages.getBulkStatus(broadcastId);
console.log(`${status.sent}/${status.total} enviados`);
```

## Manejo de errores

```ts
import {
  WhatsAppApiError,
  WhatsAppValidationError,
  WhatsAppTimeoutError,
} from "@keebai/sdk";

try {
  await wa.messages.sendText({ to: "+5491155555555", body: "hola" });
} catch (err) {
  if (err instanceof WhatsAppApiError) {
    console.log(err.status, err.code, err.message);
  }
}
```

Códigos comunes:

| Código | Status | Causa |
|---|---|---|
| `UNAUTHORIZED` | 401 | Token revocado o no válido. |
| `FORBIDDEN` | 403 | El token no tiene el scope requerido. |
| `CHANNEL_NOT_FOUND` | 404 | `phoneNumberId` desconocido en tu company. |
| `invalid_phone` | 422 | `to` no está en formato E.164. |
| `MEDIA_REFERENCE_REQUIRED` | 400 | Media sin `link` ni `media_id`. |
| `THROTTLED` | 429 | Pasaste el rate limit (el SDK reintenta solo). |

Los 429 + 5xx + errores de red se reintentan automáticamente con backoff exponencial. Configurable:

```ts
new WhatsAppClient({
  apiKey: "kbai_pk_...",
  phoneNumberId: "100000000000001",
  timeoutMs: 30_000,
  retries: 2,                              // default
});
```

## Modo Meta directo

Cuando preferís ir directo a Meta sin la plataforma:

```ts
const wa = new WhatsAppClient({
  accessToken: process.env.META_ACCESS_TOKEN!,
  phoneNumberId: process.env.META_PHONE_NUMBER_ID!,
});
```

| Concern | Modo `keebai` | Modo `meta` |
|---|---|---|
| Auth | PAT (`kbai_pk_...`) desde app.keebai.com | Access token (`EAA...`) desde developers.facebook.com |
| Persistencia | Sí — conversaciones, mensajes, contactos | No — Meta no guarda historial |
| Webhooks normalizados | Sí — envelope `{ event, data, timestamp }` con firma HMAC | No — Meta envelope crudo |
| Broadcasts (`sendBulk`) | Sí | No disponible |
| Templates CRUD | Sí | No en este SDK; usar Business Management API |
| Dashboard | Sí | No |
| Multi-tenant | Un PAT, múltiples canales | Un token por WABA |
| Send messages | Cobertura completa | Cobertura completa |

```ts
const template = buildTemplateSendPayload({

const phone = normalizePhone("(54) 9 11-5555-5555"); // "+5491155555555"
```
