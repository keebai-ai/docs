```bash
npm install -g @keebai/cli
keebai login
keebai whatsapp messages send --to +5491155555555 --text "Hola desde Keebai"
```

## Superficie técnica

| Producto | Descripción | Lenguaje |
|---|---|---|
| API REST | `api.keebai.com/v1` — REST + JSON, versionada, OpenAPI 3, auth por PAT. | HTTP |
| SDK | [`@keebai/sdk`](/dev/sdks/typescript) — cliente oficial Keebai/Meta dual-mode. | TypeScript / Node.js / Edge |
| CLI | [`@keebai/cli`](/dev/sdks/cli) — comandos `login`, `whoami`, `whatsapp connect`, `messages send`. | Cualquier shell |
| Agent Skills | [`keebai-ai/agent-skills`](/dev/sdks/agent-skills) — capacidad para agentes IA. | Claude Code, Cursor, Codex, Gemini CLI… |
| Webhooks | Eventos firmados con HMAC, retries, deduplicación por `event_id`. | Cualquier backend HTTPS |

## Auth en una línea

Todas las llamadas usan un Personal Access Token como Bearer:

```bash
curl https://api.keebai.com/v1/me \
  -H "Authorization: Bearer kbai_pk_<hex64>"
```

Conseguilo desde el [portal](https://app.keebai.com) (System Settings → API Keys) o desde la CLI con `keebai login`. Más detalle en [Obtener un API Key](/dev/api-keys) y [Autenticación](/dev/authentication).
